🎂 BIRTHDAY CARD — How to use this template
═══════════════════════════════════════════════

Hi! This is a customizable birthday card you can send to your friends.
Just unzip, edit a few things, re-zip, and send. Works fully offline.

──────────────────────────────────────────────
WHAT'S IN THIS FOLDER
──────────────────────────────────────────────
• index.html ........ the card itself (open this to test)
• photos/ ........... folder where you put your photos
• README.txt ........ this file

──────────────────────────────────────────────
HOW TO CUSTOMIZE (takes ~2 minutes)
──────────────────────────────────────────────

STEP 1 — Change the friend's name & message
────────────────────────────────────────────
Open index.html in any text editor (Notepad, VS Code, etc.).

Scroll down to find this section (around line ~480):

    const CONFIG = {
      friendName: "Sarah",       ← change this to your friend's name
      yourName: "Naveen",        ← your name (shows at the bottom)
      sealInitial: "N",          ← the letter on the envelope wax seal
      message: "May your year...", ← your personal message
      subtitle: "wishing you the most wonderful day",
      photos: [ ... ]
    };

Just change the text inside the quotes. That's it.


STEP 2 — Add your photos
────────────────────────
Drop 1–6 photos into the /photos folder.
Name them: photo1.jpg, photo2.jpg, photo3.jpg, ... photo6.jpg

You can also use .png — just update the filenames in the CONFIG section.

Tip: square-ish photos look best. The card auto-crops them anyway,
so don't worry too much. If you have fewer than 6 photos, the missing
ones just show a friendly placeholder.


STEP 3 — Test it
────────────────
Double-click index.html — it should open in your browser.
Click the "Open" button. Confetti, balloons, photos, song. 🎉


STEP 4 — Send to your friend
────────────────────────────
Right-click the whole "birthday-card" folder → "Send to" → "Compressed (zipped) folder"
(or on Mac: right-click → "Compress")

Send the .zip file via WhatsApp / email / Telegram / wherever.

Your friend just needs to:
  1. Unzip the file
  2. Double-click index.html

…and the card opens in their browser. No internet needed.

──────────────────────────────────────────────
MAKING IT EVEN BETTER (optional)
──────────────────────────────────────────────

• To use your own song instead of the built-in melody:
    – Save your song as song.mp3 in this folder.
    – Find the line:   playHappyBirthday();
      in index.html and replace it with:
        const a = new Audio('song.mp3'); a.play();
    – (Only use songs you have rights to — original recordings, or
       things you've made yourself.)

• To change colors: scroll to the top of the <style> section and
  edit the values under :root { --primary: ... etc. }

• To change fonts: replace the Google Fonts link near the top.

──────────────────────────────────────────────
HEADS UP
──────────────────────────────────────────────

• The Google Fonts link at the top loads fonts from the internet.
  If your friend opens it offline, it still works — just falls back
  to system fonts. The card will look 95% the same.

• The "Happy Birthday" tune is generated by the browser itself
  (Web Audio API), so no music file needed. It plays the moment
  they click Open.
